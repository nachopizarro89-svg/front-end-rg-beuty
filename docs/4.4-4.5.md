# 4.4 Tecnologías e infraestructura

| Tecnología | Situación |
|---|---|
| React | Frontend actual |
| Vite | Desarrollo y build |
| Firebase Authentication | Seguridad/autenticación |
| Firebase Firestore | Base de datos NoSQL actual |
| Django | Backend previsto |
| MySQL | Por el momento no aplica |
| API REST | Considerada para futuras integraciones |
| GitHub | Repositorio/publicación |

# 4.5 Diseño y prototipado

El prototipo usa un dashboard orientado al módulo de inventario. Incluye navegación lateral, indicadores, productos, búsqueda, filtros, entradas, salidas, ajustes, historial, autenticación y diseño responsive.

No se implementa localStorage. La persistencia corresponde a Firestore cuando Firebase está configurado.
